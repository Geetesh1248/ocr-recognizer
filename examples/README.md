# Example inputs and label shapes

`demo_page.pdf` and `demo_page.png` are illustrative pages generated by `create_demo.py`. They contain printed questions, a simple bordered table and a slight tilt. They let you run preparation immediately. They are not evidence of OCR accuracy or a suitable complete training dataset.

From the project root:

```powershell
..\.venv\Scripts\python.exe cli.py run examples\demo_page.pdf --until 1 --output outputs\my_preparation_demo
```

The JSON/JSONL files show expected annotation shapes. Their image filenames are placeholders, not bundled labelled datasets. Replace them with actual prepared pages or line crops and labels. Keep train and validation documents separate.
